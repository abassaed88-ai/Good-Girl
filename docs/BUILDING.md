# بناء التطبيق والتحقق منه

## البناء السحابي
يعمل سير GitHub Actions الموجود في `.github/workflows/android-build.yml` عند كل تحديث إلى فرع `main`، وعند طلب دمج، ويمكن تشغيله يدوياً من تبويب Actions إذا كانت صلاحيات المستودع تسمح بذلك.

ينفذ السير:
1. إعداد JDK 17 وGradle 8.11.1.
2. تشغيل اختبارات الوحدة.
3. إنشاء نسخة Debug APK.
4. رفع APK كعنصر Artifact باسم `good-girl-debug-apk` لمدة 14 يوماً.

## تنزيل APK من الهاتف
1. افتح صفحة المستودع على GitHub.
2. افتح تبويب Actions.
3. اختر أحدث تشغيل باسم Android build.
4. انتظر ظهور حالة النجاح.
5. افتح التشغيل ونزّل `good-girl-debug-apk` من Artifacts.

لا يُسلّم APK على أنه صالح قبل نجاح البناء والاختبارات وفحص ملف الناتج.

## ملاحظة
المشروع في هذه المرحلة تأسيسي. شاشة لوحة التحكم تعرض صفراً وبيانات تجريبية فقط؛ لا تمثل سجلات محاسبية حقيقية بعد.
