# نظام المحاسبة المتكامل للبيع بالتجزئة

تطبيق أندرويد عربي لإدارة المبيعات والمشتريات والمخزون والحسابات والديون والتقارير.

## مبادئ المشروع
- **Offline-First:** العمليات الأساسية تعمل محلياً دون اشتراط الاتصال بالإنترنت.
- **العربية أولاً:** واجهات من اليمين إلى اليسار، وجميع النصوص والحقول والتقارير باللغة العربية.
- **الأرقام إنكليزية حصراً:** 0123456789.
- **العملات المدعومة في الفواتير والحركات:** الليرة السورية والدولار الأمريكي، مع حفظ لقطة سعر الصرف في المستند.
- **هوية الواجهات:** الأزرق والرمادي الفاتح والأبيض والأخضر الفاتح والأحمر والبنفسجي. يمنع استخدام الأصفر والبرتقالي ودرجاتهما.

## الوحدات المستهدفة
المبيعات، فواتير البيع والشراء، المخزون والجرد، المنتجات والتصنيفات ووحدات القياس، العملاء والموردون، الحسابات والديون والدفعات، الصندوق، المصروفات والإيرادات، الأرباح والخسائر، التقارير، العملات، والطباعة وPDF.

## وظائف موجودة في النسخة التطويرية
- قاعدة بيانات محلية Room / SQLite.
- إدارة المنتجات وإضافة وعرض وتعديل بيانات المنتج.
- تسجيل الرصيد الافتتاحي وحركات تسوية المخزون ضمن معاملات قاعدة بيانات.
- إدارة العملاء والموردين والأرصدة الافتتاحية وكشوف الحساب.
- تسجيل الإيرادات والمصروفات وحركات الصندوق العامة.
- إنشاء فواتير بيع وشراء متعددة البنود وترحيلها مع تحديث المخزون والدفعات والأرصدة ضمن معاملة واحدة.
- استخدام متوسط تكلفة مرجّح عند الشراء، وحفظ لقطة الكلفة وسعر الصرف لكل فاتورة.
- تقارير مالية أساسية حسب اليوم أو الشهر أو كامل المدة، مع إبقاء العملات منفصلة.
- تحليل ربحية المواد اعتماداً على كلفة الوحدة المحفوظة وقت البيع، وتوزيع خصم الفاتورة على بنودها.
- اختبارات وحدات لمنطق المدخلات والحسابات والتقارير.
- بناء Android APK تلقائياً عبر GitHub Actions.

## ما يزال قيد التطوير والتحقق
هذه نسخة تطويرية وليست إصداراً نهائياً. ما يزال يلزم استكمال واختبار التسويات والتحصيلات المستقلة، والقيود المحاسبية التفصيلية، والتقارير المتقدمة، وإدارة سجل أسعار الصرف والتحويلات، والطباعة وPDF، والنسخ الاحتياطي والاستعادة، إضافة إلى اختبارات الاستخدام على أجهزة أندرويد فعلية.
