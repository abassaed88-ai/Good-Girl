# نظام المحاسبة المتكامل للبيع بالتجزئة

تطبيق أندرويد عربي لإدارة المبيعات والمشتريات والمخزون والحسابات والديون والتقارير.

## مبادئ المشروع
- **Offline-First:** جميع العمليات الأساسية تعمل محلياً دون اتصال بالإنترنت.
- **المزامنة اختيارية:** عند توفر الإنترنت يمكن إضافة مزامنة ونسخ احتياطي سحابي دون جعل الاتصال شرطاً لتشغيل التطبيق.
- **العربية أولاً:** واجهات من اليمين إلى اليسار، وجميع النصوص والحقول والتقارير باللغة العربية.
- **الأرقام إنكليزية حصراً:** 0123456789.
- **العملات:** الليرة السورية والدولار الأمريكي مع سجل لأسعار الصرف.
- **هوية الواجهات:** الأزرق والرمادي الفاتح والأبيض والأخضر الفاتح والأحمر والبنفسجي. يمنع استخدام الأصفر والبرتقالي ودرجاتهما.

## الوحدات المستهدفة
المبيعات، فواتير البيع والشراء، المخزون والجرد، المنتجات والتصنيفات ووحدات القياس، العملاء والموردون، الحسابات والديون والدفعات، الصندوق، المصروفات والإيرادات، الأرباح والخسائر، التقارير، العملات، والطباعة وPDF.

## الحالة
المستودع بدأ فارغاً. يجري تأسيس المشروع من الصفر، ولن تُعلن أي مرحلة مكتملة قبل البناء والاختبار والتحقق منها.


## وظائف تم تنفيذها في النسخة التطويرية

- قاعدة بيانات محلية Room / SQLite وتعمل أساساً دون اتصال.
- إدارة المنتجات: إضافة وعرض وتعديل بيانات المنتج.
- تسجيل الرصيد الافتتاحي كحركة مخزون مستقلة ضمن معاملة واحدة.
- تسوية حركة مخزون موجبة أو سالبة مع منع الرصيد السالب.
- إدارة العملاء والموردين وتعديل بياناتهم.
- إنشاء فواتير بيع وشراء متعددة البنود.
- ترحيل الفاتورة مع تحديث المخزون والدفعات والأرصدة ضمن معاملة واحدة.
- استخدام متوسط تكلفة مرجّح عند الشراء، وحفظ لقطة الكلفة وسعر الصرف لكل فاتورة.
- اختبارات منطقية للمدخلات والحسابات الأساسية.
- بناء Android APK واختباره تلقائياً عبر GitHub Actions.

> هذه نسخة تطويرية. التسويات والتحصيلات المستقلة والقيود التفصيلية والتقارير المتقدمة والعملات وإدارة سعر الصرف والطباعة والنسخ الاحتياطي ما زالت ضمن مراحل التنفيذ، ولا تعتبر مكتملة قبل الاختبار.
