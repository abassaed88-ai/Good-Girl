# قاعدة البيانات المحلية

الإصدار الأول يضع أساس الجداول التالية: التصنيفات، المنتجات، الأطراف (العملاء والموردون)، الفواتير وبنودها، حركات المخزون، والقيود المالية.

## قواعد سلامة البيانات
- تحفظ المبالغ والكميات كنصوص عشرية دقيقة، ولا تمر عبر Double.
- تحتفظ بنود الفاتورة بلقطات اسم المنتج والوحدة والكلفة وسعر البيع وقت المستند.
- يحتفظ كل مستند بلقطة العملة وسعر الصرف.
- ترتبط حركات المخزون والقيود بالمصدر عبر sourceType وsourceId.
- لا يتم حذف المستندات المرحلة نهائياً؛ يضاف لاحقاً مسار الإلغاء والقيد العكسي.
- يجب ترحيل الفاتورة وبنودها وحركات المخزون والقيود ضمن معاملة Room واحدة.
- هذه الجداول بنية تأسيسية؛ لا تُعد دورة البيع أو الشراء مكتملة حتى تنفيذ حالات الاستخدام واختبار الترحيل والرجوع.

## التشغيل
تُنشأ قاعدة البيانات محلياً باسم good_girl_accounting.db ولا تحتاج اتصال إنترنت.
